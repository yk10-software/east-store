# EAST Women's Life Style — متجر أونلاين

موقع متجر لـ EAST (ألبسة، أحذية وشنط نسائية — دمشق، ضاحية قدسيا، ساحة تروي).
الزبونة بتختار القطع والمقاسات، وبتعبي اسمها وعنوانها، وبينفتح واتساب برسالة طلب جاهزة لرقم المحل.

> **ملاحظة:** هي نسخة تجريبية للعرض على صاحب المحل. الأسعار مبدئية والصور مقصوصة من انستغرام، ولازم تتبدل بالأسعار والصور الأصلية قبل ما ينزل الموقع أونلاين.

## الملفات

- `index.html` — الموقع كامل (HTML + CSS + JS بملف واحد، بدون مكتبات)
- `images/` — صور المنتجات

## التعديل

كل الإعدادات بأول الـ `<script>` بـ `index.html`:

| شو بدك تغيّر | وين |
|---|---|
| رقم واتساب | `STORE.whatsapp` (صيغة دولية بدون + مثل `963958589161`) |
| المنتجات والأسعار والمقاسات | مصفوفة `PRODUCTS` |
| قطعة جديدة | `tag:'new'` |
| عرض/خصم | `old:` السعر قبل الخصم |
| صور الرفوف بالواجهة | `NICHES` |

لإضافة منتج: حط الصورة بـ `images/` وزيد سطر بـ `PRODUCTS`:

```js
{id:'p24', name:'اسم القطعة', cat:'bags', price:2000, img:'اسم_الصورة', sizes:['S','M','L'], desc:'وصف قصير'},
```

الأقسام المتاحة لـ `cat`: `bags` · `shoes` · `clothes` · `acc`

## التشغيل

افتح `index.html` بأي متصفح. ما في build ولا سيرفر.
